# Navigation Menu Spec - Application Shell

Navigation Manager mengontrol tautan bilah kiri (Sidebar) untuk mengakses modul-modul workspace utama.

---

## 1. Daftar Tautan Navigasi (Navigation Registry)

Katalog navigasi default memuat:
1. **Projects**: `/projects` (Mengelola daftar folder proyek).
2. **Landing**: `/landing` (Menjalankan One-Click Generate dan simulator preview).
3. **SEO**: `/seo` (Mengonfigurasi domain, meta titles, robots, sitemaps).
4. **Google Ads**: `/google-ads` (Menyusun kampanye naskah iklan Google).
5. **Meta Ads**: `/meta-ads` (Menyusun kampanye naskah iklan Facebook/Instagram).
6. **Deploy**: `/deploy` (Mengatur target hosting CDN Cloudflare Pages).
7. **Analytics**: `/analytics` (Memantau grafik kunjungan dan kontak masuk WhatsApp).
8. **Settings**: `/settings` (Preferensi visual theme dan kunci API).

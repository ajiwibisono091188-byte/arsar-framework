# Framework Library - Conversion Knowledge Engine

Conversion Knowledge Engine merangkum 10 metadata kerangka kerja konversi pemasaran untuk menyusun struktur alur baca landing page:

---

## 1. AIDA (Attention, Interest, Desire, Action)
- **Terbaik untuk**: Pintu masuk utama promosi landing page dingin (Cold Traffic).
- **Struktur**: Menarik perhatian &rarr; Mengikat minat &rarr; Memantik keinginan &rarr; Mengajak aksi.

## 2. PAS (Problem, Agitate, Solve)
- **Terbaik untuk**: Menawarkan jasa yang mendesak memecahkan masalah mendalam.
- **Struktur**: Mengangkat masalah &rarr; Memperjelas dampak buruk masalah &rarr; Menawarkan solusi.

## 3. BAB (Before, After, Bridge)
- **Terbaik untuk**: Industri kecantikan, kebugaran, dan spa relaksasi.
- **Struktur**: Kondisi buruk masa lalu &rarr; Kondisi indah masa depan &rarr; Jembatan produk/layanan Anda.

## 4. StoryBrand (Hero, Problem, Guide, Plan, Action, Failure, Success)
- **Terbaik untuk**: Company profile instansi bisnis lokal.
- **Struktur**: Menjadikan pelanggan pahlawan dan produk sebagai pemandu terpercaya.

---

# User Personas - ARSAR Studio

Berikut adalah profil rincian 3 target persona pengguna utama **ARSAR Studio**.

---

## 1. Persona 1: Digital Marketing Agency (Agensi Pemasaran)
- **Nama Profil**: Anita, Head of Performance Marketing
- **Tujuan**:
  - Meluncurkan 15-20 landing page per minggu untuk pengujian kampanye iklan Facebook/Google Ads.
  - Meminimalkan bounce rate akibat halaman lambat agar menghemat budget budget iklan.
- **Tantangan**:
  - Kolaborasi antardesainer, copywriter, dan tim developer lambat.
  - Website builder WordPress sering crash atau lambat saat mendapat traffic tinggi iklan.
- **Kebutuhan**:
  - Pengisian copywriting landing page instan berbasis input AI.
  - Export static pages cepat yang siap dideploy ke server agensi secara gratis.
- **Workflow**:
  ```text
  Analisis Keyword Iklan → Input Brief Produk ke AI → AI Generate Konten JSON → Review & Build static HTML → Deploy Gratis ke Cloudflare → Connect Domain Iklan
  ```

---

## 2. Persona 2: Freelancer (Pembuat Web Mandiri)
- **Nama Profil**: Rian, Freelance Web Developer
- **Tujuan**:
  - Menyerahkan website komersial cepat ke klien dengan garansi performa SEO maksimal.
  - Mengurangi waktu perakitan code boilerplate website dari nol.
- **Tantangan**:
  - Klien sering meminta perubahan copywriting secara mendadak.
  - Biaya sewa VPS bulanan untuk website klien memberatkan pengeluaran bulanan.
- **Kebutuhan**:
  - Pemisahan data dan UI layout agar klien bisa edit teks JSON sendiri tanpa merusak susunan kode HTML/CSS.
  - Standardisasi schema SEO Google secara built-in.
- **Workflow**:
  ```text
  Gunakan Boilerplate ARSAR → Setup theme.json warna branding klien → Tulis data company.json → Build & Serahkan file zip statis ke klien
  ```

---

## 3. Persona 3: UMKM / Pemilik Bisnis Lokal
- **Nama Profil**: Pak Bambang, Pemilik Jasa BPKB Mobil
- **Tujuan**:
  - Menguasai halaman pertama hasil pencarian Google Maps untuk target kotanya (Local SEO).
  - Mendapatkan leads telepon & chat WhatsApp dari calon konsumen lokal.
- **Tantangan**:
  - Tidak mengerti pemecahan kode pemrograman atau optimasi JSON-LD.
  - Terbatasnya budget untuk menyewa agensi SEO profesional bulanan.
- **Kebutuhan**:
  - Pengisian form data sederhana dan instan.
  - Generator target kota lokal SEO yang bekerja otomatis menghasilkan puluhan halaman per wilayah.
- **Workflow**:
  ```text
  Isi Nama Usaha & Layanan → Pilih Target Kota Operasional → Klik Generate → Unggah file statis sekali bayar ke CDN hosting gratis
  ```

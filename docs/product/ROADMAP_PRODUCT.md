# Product Roadmap - ARSAR Studio

Peta jalan peluncuran produk **ARSAR Studio** dari tahap eksperimen Alpha hingga rilis stabil produksi **v1.0.0**.

---

```text
Q3 2026: ARSAR Studio v0.1.0 (Alpha - Internal Release)
  ├── Bootstrapping Core Runtime Kernel
  ├── 11 Design Tokens & 9 Core Components
  └── CLI Static Generator Compiler
      ↓
Q4 2026: ARSAR Studio v0.5.0 (Beta - Developer Preview)
  ├── Launching GUI Interactive Playground & Config Inspector
  ├── Dynamic SEO Schema JSON-LD automation

      ↓
Q1 2027: ARSAR Studio v0.8.0 (Release Candidate - Early Adopter)
  ├── AI Copywriter Assistant & brief parser

Q2 2027: ARSAR Studio v1.0.0 (Production Stable - Public Release)
  ├── 100% stable local CMS Dashboard (Desktop App)
  ├── Plugin ecosystem market (CRM & Ads integrations)
  └── Lighthouse Scores Audit Verification (Performance >= 98, SEO 100)
```

## Target Fitur Utama Per Rilis

### 1. Alpha Release (`v0.1.0` - `v0.4.0`)
Fokus pada keandalan core engine (Data Contract Engine, Runtime Kernel, Design Tokens, Nunjucks macros). Target pengguna: Internal developers & PM.

### 2. Beta Release (`v0.5.0` - `v0.7.0`)
Menyediakan antarmuka visual preview (Playground) agar non-developer dapat melihat keselarasan token desain. Mengaktifkan kompilasi otomatis Schema.org dan integrasi webhook deployment. Target pengguna: Freelancers & Early agencies.

### 3. Release Candidate (`v0.8.0` - `v0.9.9`)
Pemasangan asisten AI untuk pembuatan materi penulisan konten web statis secara terarah. Uji coba target kota lokal untuk mendominasi peringkat peta Google lokal.

### 4. General Availability (`v1.0.0`)
Peluncuran dashboard CMS lokal berbentuk aplikasi desktop (Electron) yang memudahkan UMKM merakit website tanpa menulis baris perintah command terminal.

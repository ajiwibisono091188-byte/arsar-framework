# Feature Map - ARSAR Studio

Peta fitur **ARSAR Studio** dikelompokkan ke dalam 9 kategori modular pendukung operasional pemasaran.

---

## 1. Project Management
- **Project Initializer**: Membuat folder proyek statis, menyalin config default, dan mengaktifkan loader.
- **Project Cloner**: Menyalin seluruh konfigurasi proyek lama untuk dipasangkan ke domain baru (*reusability*).
- **Project Export**: Mengemas aset proyek menjadi file ZIP terkompresi.

---

## 2. AI Assistant Engine
- **Brief Parser**: Mengolah input teks deskripsi pendek dari pengguna menjadi terstruktur.
- **Copywriting Generator**: Menghasilkan draf konten untuk block Hero, FAQ, Pricing, dan Benefit.
- **Local SEO Auto-generator**: Menghasilkan konten dinamis bertarget regional kota/daerah secara unik.

---

## 3. Content Management
- **Markdown Editor**: Editor markdown dinamis untuk memfasilitasi tulisan berita / artikel blog.
- **Media Asset Manager**: Folder pengelola unggahan gambar dan optimasi kompresi otomatis (WebP converter).
- **Form Builder**: GUI pembuat kolom formulir kontak kustom.

---

## 4. Built-in SEO Optimization
- **Dynamic Meta Tags Injector**: Pengisian meta title, description, dan og-image otomatis.
- **JSON-LD Schema Creator**: Otomatisasi perakitan FAQ Page, LocalBusiness, dan Breadcrumb list.
- **Sitemap & Robots Generator**: Pembuatan file `sitemap.xml` dan `robots.txt` otomatis saat build.

---

## 5. Paid Ads Helper
- **UTM Parameter Linker**: Otomatis melacak link campaign iklan.
- **Dynamic Parameter Injector**: Menyisipkan kata kunci kueri pencarian iklan secara dinamis ke teks heading website.

---

## 6. Zero-Cost Deployment
- **Cloudflare Pages Connector**: Deploy static pages sekali klik ke infrastruktur Cloudflare.
- **Build Logger**: Console log pelacak keberhasilan build.
- **SSL Auto-configurator**: Mengaktifkan https aman gratis.

---

## 7. Analytics & Tracking
- **Tag Manager Injector**: Pemasangan script tag GTM dan GA4.
- **Ad Pixel Connector**: Pemasangan Facebook Pixel tanpa memberatkan performa rendering visual.

---

## 8. Theme & Settings
- **Branding Color Customizer**: Pengatur warna primer dan sekunder hex dengan visual picker.
- **Font & Border Selector**: Pengubah font family dan tingkat kelengkungan radius.

---

## 9. Modular Plugins
- **Plugin Registry**: Menu pasang/lepas plugin eksternal kustom (misal: CRM HubSpot webhook).

# Copywriting Rules & Character Limits - Google Ads Generator

Headline dan deskripsi disusun mengikuti kaidah kepatuhan ketat mesin Google Ads demi kelayakan tayang iklan.

---

## 1. Aturan Batas Karakter Resmi

- **Headline**: Panjang string &le; **30 karakter**. Jika melebihi batas, Google Ads Editor akan memunculkan status error merah.
- **Description**: Panjang string &le; **90 karakter**.

---

## 2. Strategi Distribusi Porsi Teks

Untuk performa rasio klik (CTR) maksimal, 30 headline dibagi rata:
- **Porsi Keyword (10 headline)**: Mengulang kata kunci target seperti "Gadai BPKB Surabaya".
- **Porsi USP (10 headline)**: Menonjolkan keuntungan seperti "Bunga Ringan 0.8%".
- **Porsi CTA (10 headline)**: Ajakan bertindak interaktif seperti "Cek Angsuran Gratis".
- **Porsi Brand**: Menyebutkan nama perusahaan.

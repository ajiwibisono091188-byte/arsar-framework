# Testimonial Schema Documentation

## Purpose
Menyusun skema data ulasan / ulasan kepuasan pelanggan (social proof).

## Structure
- `name` (string)
- `position` (string)
- `avatar` (string)
- `content` (string)
- `rating` (number)

## Required Fields
- `name`
- `content`
- `rating`

## Validation Rules
- `rating` wajib berupa angka bulat desimal antara 1 (minimal) s.d 5 (maksimal).

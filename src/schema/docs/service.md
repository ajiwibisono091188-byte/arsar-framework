# Service Schema Documentation

## Purpose
Menyusun data spesifikasi layanan bisnis perusahaan.

## Structure
- `title` (string)
- `description` (string)
- `icon` (string)
- `slug` (string)

## Required Fields
- `title`
- `description`
- `slug`

## Validation Rules
- `slug` wajib berupa rangkaian huruf kecil, angka, dan tanda hubung saja (format slug URL valid).

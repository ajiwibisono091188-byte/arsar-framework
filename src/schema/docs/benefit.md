# Benefit Schema Documentation

## Purpose
Menyusun data keunggulan utama produk/layanan (value propositions).

## Structure
- `id` (string)
- `title` (string)
- `description` (string)
- `icon` (string)

## Required Fields
- `title`
- `description`

## Validation Rules
- `title` disarankan maksimal 30 karakter agar tidak merusak keselarasan grid card.

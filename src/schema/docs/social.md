# Social Schema Documentation

## Purpose
Menyimpan tautan akun sosial media resmi instansi untuk ornamen visual dan social metadata sharing.

## Structure
- `facebook` (string, URL format)
- `instagram` (string, URL format)
- `twitter` (string, URL format)
- `linkedin` (string, URL format)
- `youtube` (string, URL format)

## Required Fields
*(Tidak ada field wajib, seluruh properti bersifat opsional)*

## Validation Rules
- Seluruh properti yang diisi wajib berformat URL valid yang diawali oleh protokol `http://` atau `https://`.

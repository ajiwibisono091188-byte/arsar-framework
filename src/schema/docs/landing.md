# Landing Schema Documentation

## Purpose
Mengatur penampilan modular komponen marketing block pada tata letak landing page.

## Structure
- `featuresBlockEnabled` (boolean)
- `testimonialsBlockEnabled` (boolean)
- `faqBlockEnabled` (boolean)
- `ctaBlockEnabled` (boolean)
- `calculatorBlockEnabled` (boolean)

## Required Fields
- `featuresBlockEnabled`
- `testimonialsBlockEnabled`
- `faqBlockEnabled`
- `ctaBlockEnabled`

## Validation Rules
- Seluruh field bertipe boolean wajib diisi nilai true/false secara eksplisit.

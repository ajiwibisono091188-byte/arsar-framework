# SEO Schema Documentation

## Purpose
Menyusun skema data meta tag global dan indexing crawler robot search engine.

## Structure
- `defaultTitle` (string)
- `titleTemplate` (string)
- `defaultDescription` (string)
- `robots` (string)
- `charset` (string)
- `openGraph` (object)

## Required Fields
- `defaultTitle`
- `defaultDescription`
- `robots`

## Validation Rules
- `defaultDescription` sebaiknya minimal 100 karakter dan maksimal 160 karakter agar optimal dibaca Google Search.

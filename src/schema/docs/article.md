# Article Schema Documentation

## Purpose
Menyusun meta data / metadata di atas halaman artikel blog (front-matter).

## Structure
- `title` (string)
- `description` (string)
- `datePublished` (string, format YYYY-MM-DD)
- `author` (string)
- `image` (string)
- `category` (string)

## Required Fields
- `title`
- `description`
- `datePublished`
- `author`

## Validation Rules
- `datePublished` wajib berformat penanggalan internasional `YYYY-MM-DD` (contoh: `2026-07-25`).

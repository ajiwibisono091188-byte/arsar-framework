# Schema Directory

Direktori ini berisi template Schema.org dalam format JSON-LD yang dikompilasi oleh `schema-generator.js` secara dinamis. Schema markup membantu search engine memahami entitas bisnis dan konten di dalam website untuk menampilkan rich snippets.

## Berkas Schema
- `Organization.json`: Menjelaskan data organisasi perusahaan.
- `LocalBusiness.json`: Membantu optimasi Local SEO dengan memetakan wilayah target per kota.
- `FAQ.json`: Menghasilkan schema FAQ page dinamis dari data `faq.json`.
- `Breadcrumb.json`: Menghasilkan struktur jejak halaman (breadcrumb list).
- `Article.json`: Digunakan pada halaman detail artikel/blog.
- `Service.json`: Mendeskripsikan layanan spesifik yang ditawarkan.

# Design Tokens Folder

Folder ini menyimpan 11 file konfigurasi JSON yang mewakili nilai atomik dari Design System.

## Daftar Token
- `colors.json`: Palet warna primer, sekunder, netral, status (success, info, dll), dan mode gelap/terang.
- `typography.json`: Konfigurasi jenis font, ukuran, tinggi baris (`line-height`), dan ketebalan huruf.
- `spacing.json`: Skala jarak margin, padding, dan gap layout.
- `radius.json`: Skala sudut kelengkungan (border-radius).
- `shadow.json`: Aturan bayangan / elevasi kotak.
- `animation.json`: Skala durasi transisi dan efek animasi (spin, bounce, pulse).
- `breakpoints.json`: Titik responsivitas viewport perangkat.
- `zindex.json`: Pengaturan susunan tumpukan layer sumbu-Z.
- `opacity.json`: Aturan tingkat transparansi/transparansi kaca.
- `transition.json`: Properti transisi transisi CSS dan kurva kecepatan bezier.
- `container.json`: Aturan pembungkus lebar maksimal konten halaman.

# Config Directory

Direktori ini berisi file konfigurasi berbasis JSON untuk mengontrol tema global, data perusahaan, kode tracking analytics, default SEO, dan struktur navigasi.

## Daftar File Konfigurasi
- `theme.json`: Menyimpan token desain dasar seperti warna, font, layout, dan ukuran default (termasuk setting light/dark mode).
- `company.json`: Berisi data profil perusahaan yang digunakan oleh schema generator dan komponen kontak/footer.
- `tracking.json`: Konfigurasi ID pihak ketiga (Google Analytics, GTM, FB Pixel, TikTok Pixel, Clarity).
- `seo.json`: Berisi fallback metadata SEO global, termasuk struktur OpenGraph dan Twitter Card.
- `navigation.json`: Menyusun urutan menu navigasi header, footer link, serta relasi parent-child menu.

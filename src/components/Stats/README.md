# Stats Component

Komponen angka statistik utama untuk memperkuat social proof atau keunggulan performa teknologi.

## Desain & Warna
- **Gradient Text**: Angka stat utama menggunakan gradien teks premium (`.text-gradient`) agar langsung menarik perhatian mata.
- **Responsive Columns**: Menggunakan sistem grid 2-kolom di mobile dan 4-kolom di layar lebar (desktop).

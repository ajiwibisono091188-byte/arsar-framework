# Timeline Component

Komponen kronologis vertikal (Timeline) untuk mendeskripsikan langkah-langkah kerja atau roadmap proses layanan.

## Desain & Struktur
- **Timeline Line**: Dibuat menggunakan manipulasi border sebelah kiri (`border-l`) dengan padding-left yang presisi.
- **Responsive Layout**: Konten berpindah dari layout satu kolom di mobile ke layout dua kolom (side-by-side) di layar medium (desktop).

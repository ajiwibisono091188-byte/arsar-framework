# Benefit Component

Komponen grid yang menyajikan keunggulan utama produk/jasa (value propositions).

## Fitur Desain
- **Interactive Hover Glow**: Menggunakan class `.glow-card` yang mengukur posisi mouse koordinat (`--mouse-x` & `--mouse-y`) untuk membuat kilauan latar belakang reaktif.
- **Numbered Badge**: Indikator penomoran visual yang rapi dengan kombinasi opacity latar belakang.

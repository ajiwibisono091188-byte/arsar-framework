# Testimonials Component

Komponen untuk menyajikan ulasan dan kepuasan pelanggan (social proof).

## Struktur Data
- **Dynamic Render**: Data diimpor secara dinamis dari file data JSON `testimonials.json`.
- **Loops & Conditions**: Menghitung jumlah perulangan bintang berdasarkan prop `rating` menggunakan sintaks loop Nunjucks.

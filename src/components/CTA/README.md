# CTA Component

Komponen Call-To-Action (CTA) premium yang dioptimalkan untuk menarik konversi pengunjung. Dibuat dengan modul glassmorphism panel (`.glass-panel`) dan radial gradient glow di ujung-ujung wadahnya.

## Fitur Desain
- **Button Prominent**: Dua tombol pilihan aksi dengan prioritas visual kontras tinggi (solid white vs emerald whatsapp green).
- **Glassmorphism Backdrop**: Menggunakan background blur dengan border transparan tipis.

# ContactForm Component

Komponen penangkap data lead (Formulir Kontak) untuk halaman pemasaran.

## Desain & Styling
- **Forms CSS Integration**: Menggunakan class `.form-input-custom` yang telah didesain di `src/assets/css/forms.css` untuk mendapatkan border focus ring glow reaktif.
- **Semantic Fields**: Form input terhubung dengan id dan label unik untuk lolos Accessibility standard (>95).

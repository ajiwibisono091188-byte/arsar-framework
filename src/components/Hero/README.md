# Hero Component

Halaman utama (banner) yang diletakkan di bagian atas (above the fold). Didesain dengan tipografi premium, sub-badge modern, dan gradien latar belakang mesh yang memukau.

## Fitur & Animasi
- **Scroll Reveal**: Menggunakan class `.scroll-animate` yang dideteksi oleh `IntersectionObserver` di `animation.js` untuk memicu efek pudar ke atas (`.animate-fade-in`).
- **Aset Latar Belakang**: Latar belakang mesh gradient dinamis menggunakan class `.bg-mesh-dark` dari stylesheet utility.

## Props/Variabel Nunjucks
- Dapat dikustomisasi langsung dengan variabel global perusahaan atau data halaman dinamis.

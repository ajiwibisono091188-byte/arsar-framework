# Gallery Component

Komponen galeri foto atau grid portofolio. Menampilkan screenshot mockup project dengan efek hover interaktif.

## Fitur Animasi
- **Image Hover Scale**: Konten visual di dalam kartu melakukan perbesaran (`scale-105`) secara halus menggunakan transisi CSS saat kartu di-hover.
- **Gradient Overlay**: Memunculkan deskripsi teks secara perlahan (`opacity-100`) menggunakan gradien warna gelap pada bagian bawah gambar.
